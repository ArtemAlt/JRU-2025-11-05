Симуляция эпидемии — техническое задание

1. Общее описание

Разработать программу для симуляции распространения эпидемии в городе. 
Город представлен в виде двумерной сетки (карты), по которой передвигаются люди. 
Каждый человек может быть здоров, находиться в инкубационном периоде, болеть, выздоравливать или умирать. 
Вирус передаётся при контакте здорового и больного человека, находящихся в одной клетке.

Программа должна иметь графический интерфейс (Swing), отображающий состояние города в реальном времени, 
а также возможность управления симуляцией (пауза, шаг, сброс).

2. Функциональные требования

2.1. Моделирование города

Город представляет собой сетку размером N x M (настраивается).
Каждая клетка может содержать любое количество людей.
Некоторые клетки являются зонами повышенной плотности (например, ТЦ, офисы, метро), что увеличивает вероятность заражения.
2.2. Моделирование людей

Каждый человек имеет следующие характеристики:

Характеристика	Описание
Тип уязвимости	Ребёнок, Взрослый, Пожилой, Медик (разная смертность и восприимчивость к вирусу)
Тип поведения	Активный, Обычный, Изоляционист, Носитель (разная частота перемещений и контактов)
Статус здоровья	Здоров, В инкубации, Болен, Выздоровел, Мёртв
Иммунитет	Приобретается после выздоровления с заданной вероятностью
2.3. Моделирование вируса

Вирус имеет следующие параметры (настраиваются):

Параметр	Описание
Тип	Грипп / COVID-19 / Эбола (выбирается случайно или задаётся)
Инфекционность	Вероятность заражения при контакте (от 0 до 1)
Летальность	Вероятность смерти заболевшего (от 0 до 1)
Инкубационный период	Количество тактов до появления симптомов
Иммунитет	Вероятность приобретения иммунитета после выздоровления
2.4. Поведение людей

На каждом такте симуляции для каждого человека выполняются следующие действия (в указанном порядке):

Обновление статуса — инкубация → болезнь, проверка на смерть.
Попытка выздоровления — с заданной вероятностью больной переходит в статус "Выздоровел".
Заражение — если в клетке есть больной или заразный носитель в инкубации, здоровые люди заражаются с вероятностью, зависящей от:

Базовой инфекционности вируса
Типа уязвимости человека
Типа поведения (множитель контактов)
Плотности населения в клетке
Перемещение — человек с вероятностью, зависящей от типа поведения и статуса здоровья, переходит в соседнюю клетку (вверх, вниз, влево, вправо).
2.5. Зоны повышенной плотности

Количество зон и их радиус настраиваются.
В этих зонах увеличивается множитель заражения.
Зоны отображаются на карте специальным цветом или наложением.
2.6. Условия остановки симуляции

Симуляция автоматически останавливается при наступлении одного из условий (настраиваются):

Все люди здоровы (эпидемия побеждена).
Все люди мертвы или переболели.
Осталось меньше заданного количества живых людей.
3. Технические требования

3.1. Конфигурация

Все параметры симуляции вынесены в файл config.properties:
Все обязательные ключи описаны в ConfigKey

3.2. Графический интерфейс (Swing)

Основные элементы:

Элемент	Описание
Карта города	Сетка из цветных клеток, цвет зависит от статуса людей в клетке
Панель статистики	Отображает текущее количество здоровых, больных, умерших и т.д.
Индикатор тика	Показывает номер текущего такта
Кнопки управления	Пауза / Пуск, Шаг, Сброс
Отображение клеток:

Зелёный оттенок — здоровые люди
Жёлтый — есть люди в инкубации
Красный — есть больные
Серый — есть мертвые
Полупрозрачное наложение — зона повышенной плотности
3.3. Статистика

На каждом такте в панели статистики отображается:

Номер тика
Тип вируса
Общее количество живых людей
Количество здоровых (в процентах)
Количество в инкубации (в процентах)
Количество больных (в процентах)
Количество выздоровевших (в процентах)
Количество умерших (в процентах)
Количество людей с иммунитетом
По окончании симуляции выводится итоговая статистика.
